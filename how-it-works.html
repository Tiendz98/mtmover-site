From install to cut-over in three steps

Every module follows the same flow: Onboard, Mapping, Migrate.

Download free trial

0. Install and sign in

  1. Download the MSI from the Download page and install it.
  2. Open MTMover. Choose Create account (it opens this website), or sign in if you already have an account.
  3. Start the free trial, or sign in with a licensed account.

1. Onboard

Connect the source and the destination tenants. A Global Administrator of each tenant signs in and grants admin consent. The source gets read-only access. MTMover reports the status of the connection on the Onboard step.

2. Mapping

  1. Click Load to list every mailbox, site, team or drive of both tenants.
  2. Click Auto-map to pair items with the same name. You are asked to confirm.
  3. Pair the rest by hand with the drop-down. You can also change an automatic pair.
  4. Use Export CSV and Import CSV to edit mappings in bulk.
  5. Click Check. Only checked pairs move to the Migrate step.

3. Migrate

  1. Tick the pairs to migrate. Dry-run is on by default.
  2. Run once as a dry-run, read the result, then clear Dry-run and start the real migration.
  3. Open the detail window of a pair to see what was migrated.
  4. Re-run before cut-over. Items that already arrived are skipped.
MTMover only copies. It never edits the source tenant.
