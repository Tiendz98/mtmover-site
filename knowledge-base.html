Account and license

  • Create account: in the app, choose Create account. It opens mtmover.tech/account. Enter your email, click Send code, enter the 6-digit code, and choose a password. The code is valid for 10 minutes.
  • Forgot password: choose Forgot Password? in the app, or open the reset page. After a reset you are signed out on all computers.
  • License: a license is linked to your account email. After we activate it, the app shows Licensed. Use Refresh or sign in again if it does not change.

Permissions and security

  • You connect each tenant by signing in as an administrator and granting admin consent.
  • The source tenant gets read-only access. MTMover copies; it does not edit the source.
  • For email, access can be limited to chosen mailboxes with Exchange RBAC for Applications.
  • Migration content goes between Microsoft 365 and your PC. The MTMover license server stores only account and license data.

Known limits

  • Trial: up to 5 items per module run for 14 days.
  • SharePoint pages: standard web parts are copied. Rebuild News, Events and People web parts by hand. Gradient section backgrounds and banner title text are not copied.
  • Hyperlink columns: values keep the original URL and are not rewritten to the new domain.
Run a dry-run first and review the result on every module before you start a real migration.
