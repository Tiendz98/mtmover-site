IMAP migration workflow

01

Inventory

List source IMAP mailboxes, confirm credentials or access method, and create the matching Microsoft 365 destinations.

02

Validate

Check connectivity and mapping with a small trial set. Resolve authentication, folder naming and destination readiness issues first.

03

Run and review

Run the migration in controlled batches, review job output and verify representative folders and messages in Microsoft 365.

Information to collect before starting

  • Source IMAP host, port and TLS requirements.
  • Source mailbox identifiers and their Microsoft 365 destination accounts.
  • Expected maintenance or cutover window.
  • A validation sample that represents small, large and nested-folder mailboxes.

MTMover runs as a desktop app on your Windows PC. Validate your specific source system and data set with the free trial before purchasing.

Verification checklist

  • Confirm the job completed for every mapped source.
  • Compare representative source and destination folders.
  • Record failures or skipped items before retrying.
  • Keep source access until business validation is complete.
