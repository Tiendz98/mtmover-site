IMAP

IMAP to Office 365 and IMAP to IMAP.

Delta re-runs

Already migrated items are skipped on the next run.

Control and safety

Dry-run by default

See what would be copied before anything is written.

Read-only source

MTMover only copies. It never edits the source tenant.

Admin consent

Tenants are connected through admin consent. For email, access can be limited to chosen mailboxes with Exchange RBAC for Applications.

Auto-map and CSV

Auto-map matches, adjust by hand, and export or import every mapping as CSV.

Check before you migrate

Only pairs that passed Check move on to the Migrate step.

Status that stays

Pair status survives a restart, and each pair has a detail window of what was migrated.
