What MTMover migrates

One tool for the four workloads that make up a tenant move.

Email

Mailbox folders and items, including nested folders, with incremental delta sync for cut-over.

OneDrive

User files and folder structure copied to the destination tenant.

SharePoint

Document libraries, lists and site pages. A whole site per run, no scope choices to get wrong.

Teams

Teams, channels, messages and file attachments.

Three steps. Nothing hidden.

The same flow for every module: Onboard, Mapping, Migrate.

Onboard

Connect the source and destination tenants with admin consent. Source access is read-only.

Mapping

Auto-map users, sites and teams. Review the pairs, change them with a drop-down, or import a CSV.

Migrate

Dry-run is on by default. Run the real migration, then re-run deltas until cut-over.

Built for IT admins who cannot afford surprises

  • Dry-run first. See what would be copied before anything is written.
  • Source stays untouched. MTMover only copies; it never edits the source tenant.
  • Re-run safely. Items that already arrived are skipped, so deltas do not create duplicates.
  • Your data stays with you. The app runs on your PC and talks to Microsoft 365 through Microsoft Graph.
