Tenant to Tenant Migration

Move Email, OneDrive, SharePoint and Teams from one Microsoft 365 tenant to another, with dry-run first and read-only access to your source.

One workflow for a complete tenant move

Mergers, acquisitions, divestitures and tenant consolidation all need the same thing: every workload moved, in order, without touching the source. MTMover gives you one Onboard, Mapping, Migrate flow for Email, OneDrive, SharePoint and Teams.

  • Dry-run is on by default
  • Source tenant is read-only: copy only, never edit
  • Auto-map users, sites and teams, then review
  • Incremental delta sync for cut-over
  • Per-pair status and a detail window of what was migrated
  • Failed items are retried on the next run

What it covers

Email

Mailbox folders and items, including nested folders. Items are exported from the source and imported into the destination in batches.

OneDrive

User files and folder structure to the destination tenant.

SharePoint

Document libraries, lists and site pages. One button migrates documents, lists and pages of a mapped site.

Teams

Teams, channels, messages and file attachments.

Delta re-runs

Re-run as often as you need before cut-over. Items already migrated are skipped.

Mapping with CSV

Auto-map, adjust with drop-downs, and export or import every mapping as CSV.

How it works

Onboard

Sign in as an admin of each tenant and grant consent. The source gets read-only access.

Mapping

Click Load to list everything in both tenants, Auto-map the matches, fix the rest by hand, then Check the pairs.

Migrate

Start with a dry-run, then migrate. Re-run to pick up new items until you cut over.

Free trial and limits

The free trial runs for 14 days and processes up to 5 items per module run, so you can test the full flow on real tenants. A license removes the trial item cap. See pricing.

SharePoint pages: standard web parts are copied. News, Events and People web parts, gradient section backgrounds and banner title text have to be rebuilt by hand on the destination page.

Frequently asked questions

Does MTMover change my source tenant?

No. MTMover only copies. The source gets read-only access.

Can I migrate in phases?

Yes. Check only the pairs you want, migrate them, and re-run later. Already migrated items are skipped.

Do I need PowerShell?

No. Onboarding, mapping and migration all run from the MTMover window.
